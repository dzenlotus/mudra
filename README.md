# Mudra

Предварительные сборки Mudra — сохраняемого AI harness на основе Ghanta и Vajra.

**[Скачать Mudra для Mac Apple Silicon](https://github.com/dzenlotus/mudra/releases/download/v0.1.0-preview.20261020.2/mudra-macos-arm64-path-graph-preview.zip)** · [Страница выпуска](https://github.com/dzenlotus/mudra/releases/tag/v0.1.0-preview.20261020.2)

## Запуск

1. Распакуйте архив.
2. Откройте `Mudra.command`: диалог появится в Терминале.
3. Выберите рабочую папку и настройте свои LLM и embedding API.
4. Напишите задачу в редакторе снизу. **Ctrl+S или F2 отправляет запрос, Enter добавляет строку.** Профиль, знания и разговор сохраняются после закрытия.

Дождитесь открытия редактора перед вставкой первого запроса: в этой preview текст, вставленный вместе с ответами мастеру настройки, может не попасть в чат.

`/help` — команды, `/model` — настроенная модель, `/settings` — настройки, `/status` — диагностика задачи, `/sessions` — сохранённые сессии, `/resume` — явное продолжение, `/new` — новый разговор, `/clear` — очистить экран, `/exit` или `/quit` — выход.

При обновлении распакуйте архив в отдельную папку и запустите новый `Mudra.command`. Сохранённый профиль выберет прежнюю рабочую папку с настройками и знаниями.

## Требования

- Mac с Apple Silicon, macOS 11 или новее.
- Совместимые Chat Completions API с вызовом инструментов и JSON-ответами и embedding API.
- Rust, Python, Node и локальные модели для самого мастера и диалога не нужны.
- Для JavaScript-процедур нужен Node с `process.getBuiltinModule`; проверена версия v24.13.1.

API-ключи задаются через окружение либо macOS Keychain. Ввод ключа в мастере скрыт; ключи не записываются в JSON-настройки. В проверочном SSH-сеансе macOS запретила запись в Keychain (OSStatus -25308); вариант с переменными окружения проверен. `.env` автоматически не загружается.

Архив содержит программу, запуск, инструкцию и контрольные суммы файлов. Рабочие базы, профили и ключи создаются на вашей машине. Рабочая папка не является sandbox: выполняемые процедуры используют права пользователя, а данные могут передаваться выбранным API.

## Что видно при работе

Публичные пояснения Гханты и наблюдавшиеся действия собраны в блок **«Ход работы»**, свёрнутый по умолчанию. Итоговый ответ виден отдельно. **F4 или щелчок по заголовку** раскрывает и сворачивает блок. Старые блоки доступны через прокрутку истории.

Внутри — зарегистрированные вызовы **Vajra: процедура@версия, правило, исход и время вызова**. Показаны записанные внешние исполнения из журнала шага; рекурсивные внутренние вызовы композиции отдельно в этот журнал не записываются. Ошибка, отклонённый кандидат и неизвестный исход обозначаются отдельно. Пояснение модели само по себе не подтверждает результат. Ход работы сохраняется с диалогом и не добавляется к контексту модели.

Справа сверху — **карта пути от входных параметров к целям**. Она использует записанный план Vajra: показывает все обязательные входы, промежуточные параметры, правила, их процедуры и относящиеся к пути активированные контексты. Входы и цели подписаны отдельно, стрелки показывают направление связей. Состояния «в плане», «выполнено» и «нет значения» различаются.

**F5 или щелчок по заголовку карты** раскрывает её на большую область: рядом с вращаемой 3D-проекцией находится полный прокручиваемый список узлов и направленных связей. Длинные имена переносятся; редактор запроса остаётся доступен. Повторное F5 возвращает диалог. Отсутствие координат не удаляет узел из списка.

Для параметров пути с подтверждёнными семантическими попаданиями используются сохранённые векторы. Другие узлы получают явно обозначенную компоновку графа. Координаты готовятся в отдельном потоке без новых вызовов моделей. Проекция служит навигации; score сходства вычисляется в исходном пространстве. Если путь или исторические связи не подтверждены, карта показывает неполные данные.

- **Ctrl+S / F2** — отправить весь запрос; **Enter** — новая строка.
- **F4** или щелчок по заголовку — раскрыть/свернуть «Ход работы».
- **F5** или щелчок по заголовку карты — развернуть карту / вернуться к диалогу.
- **Alt + стрелки** — вращать карту; **Alt + + / -** или колесо над картой — масштаб.
- **Щелчок по точке** — имя, тип и происхождение координат узла.
- **↑ / ↓** — история запросов в начале / конце всего текста.
- **PgUp / PgDn** — прокрутка диалога; в развёрнутой карте — списка узлов и связей.
- **Ctrl+D** — детали; `/status` запрашивает диагностику.
- **Ctrl+Z / Ctrl+Y** — отмена / повтор правки в редакторе.
- **Ctrl+C** — прервать текущий запуск; в ожидании очистить черновик, при пустом вводе — выйти.

Карта видна при ширине от 80 столбцов. При меньшей ширине остаётся чат. Редактор сохраняет текст при изменении размеров; длинная строка прокручивается горизонтально.

Текущий запрос выполняется в этом окне. Прерывание сохраняет исходную сессию и неизвестные результаты действий; `/resume` предоставляет явное продолжение. Сохранённая фоновая запись не доказывает активность процесса. Для построчного режима — `./bin/mudra chat --plain`.

## Проверки и статус

Проверено на Mac mini с Apple Silicon:

- 234 существующие проверки прошли: основной движок — 147, поисковое ядро — 36, CLI — 49, лимиты и история — 2. Одна проверка Keychain намеренно пропущена. Новые продуктовые тесты не добавлялись. Clippy завершился успешно с предупреждениями; отсутствие предупреждений не заявляется.
- Один новый прямой запрос с известными параметрами и целью выполнил `readFile@1` без LLM и эмбеддера. Результат — 186 байт, побайтно совпавших с файлом. Это проверка известного исполнения, без новой формализации или обучения.
- Старый диалог с чтением файла восстановился в граф из **5 узлов и 4 связей**, включая 2 точки из реальных сохранённых векторов. Посторонняя ветка преобразования документа удалена. Кеш прежнего формата больше не перезаписывает обновлённое отображение.
- Сохранённый реальный расчёт `плотность + объём → масса → сила → работа` показал **13 узлов алгоритма и 1 связанный контекст, 13 связей**. Полные имена и все направленные связи доступны в F5. Имя одного исторического контекста не сохранено: он показан как `Контекст #186`, карта честно помечена неполной; исходная задача имеет подтверждённый результат.
- При отсутствии кеша векторов все 5 узлов чтения файла остаются в компоновке графа. Проверены размеры 80×18, 80×24, 120×36 и 160×50, прокрутка полного списка, сохранение черновика, F4/F5, поворот и восстановление терминала. Исходные журналы не изменены, повторного исполнения старых задач не было.
- Окончательный архив распакован штатной утилитой macOS в путь с пробелами и русскими буквами. Текущий бинарник восстановил новый сохранённый результат и карту без повторного исполнения и обращений к API; права запуска и восстановление терминала подтверждены.

Это preview без Developer ID и нотарификации Apple. Доступ на управляемом Mac может зависеть от политики вашей организации. Общая производственная готовность и задержка с произвольными моделями этими проверками не установлены.

В Assets выпуска доступны архив, `runtime-receipt.json` со сведениями о проверках и `SHA256SUMS`.
