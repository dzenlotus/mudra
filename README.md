# Mudra

Mudra — CLI для работы с файлами и задачами в папке проекта. Гханта учит и проверяет процедуры, а Ваджра сохраняет их как правила и применяет к новым данным. Обученная сборка уже содержит системную базу знаний.

## Установка

1. Распакуйте ZIP и откройте `Install.command`. Установка выполняется для текущего пользователя без `sudo`.
2. Откройте **новое** окно Терминала, перейдите в папку своего проекта и запустите Mudra.

   ```sh
   cd "/путь/к/проекту"
   mudra
   ```

3. При первом запуске настройте модель в мастере. Если имя команды было занято, установщик покажет `mudra-work`. После установки распакованную папку можно удалить.

## Корпоративный DeepSeek или другой OpenAI-совместимый API

- В поле **«Адрес API LLM»** введите базовый URL, который выдала ваша команда, например `https://llm.example.org/v1`. Путь `/chat/completions` Mudra добавляет сама.
- Введите точный **ID модели** из вашего развёртывания. В поле **«Переменная ключа LLM»** укажите имя переменной окружения, например `MUDRA_API_KEY`. Сам ключ можно предоставить через окружение или сохранить в macOS Keychain по приглашению мастера.
- Дополнительные параметры модели можно оставить `{}`. Для эмбеддингов выберите **1 — общий сервис Mudra**. Он использует модель `rubert-tiny2` из архива.
- Чтобы сменить провайдера позже, введите в диалоге `/connect`, выберите **6 — Свой OpenAI-совместимый API**, затем откройте `/models`. Сервер должен поддерживать потоковые ответы Chat Completions (SSE) и вызовы инструментов (`tools`).

## Знания и рабочая папка

В архиве **267 параметров, 192 правила, 294 записи процедур, 12 контекстов и 79 карточек инструкций**. Включены 165 исполняемых пакетов процедур, среды Python и Node.js и локальный эмбеддер. Для разработки новых Rust-процедур потребуется Rust/Cargo. Рабочие ключи, личные настройки, переписки, журналы и экспериментальные базы исключены из поставки.

Установщик размещает обученную базу в `~/Library/Application Support/Mudra-Trained/state`. Команда из `~/.local/bin` использует эту базу из любой папки. Повторная установка того же выпуска сохраняет накопленные знания.

```sh
mudra -C "/путь/к/проекту"  # Открыть диалог в указанной папке
mudra scope                  # Посмотреть рабочую папку и область знаний
mudra --local                # Использовать расширение знаний проекта в .mudra
mudra chat --plain           # Открыть построчный диалог
```

В режиме `--local` правила проекта можно обновить из глобальной базы командой `mudra --local sync`. Для обратного переноса выбранного правила используется `mudra --local promote --rule RULE_NAME --case TRUSTED_CASE_ID`; перенос требует проверенного случая.

## Диалог и сервер

В диалоге `/help` показывает доступные команды. `/status` показывает состояние запроса, `/resume` продолжает текущую задачу, `/new` открывает новую беседу. В полноэкранном интерфейсе F4 раскрывает ход работы, F5 открывает карту, F6 — список узлов.

Для работы через HTTP запустите `mudra inline --address 127.0.0.1:8787`. Сервер принимает JSON с текстом поручения и контекстом, например `{"instruction":"Прочитай файл notes.txt","context":{}}`. Для проверки доступности используйте `GET /health`.
