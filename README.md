# Mudra

Предварительные сборки Mudra — сохраняемого AI harness на основе Ghanta и Vajra.

**[Скачать Mudra для Mac Apple Silicon](https://github.com/dzenlotus/mudra/releases/download/v0.1.0-preview.20261020/mudra-macos-arm64-tui-preview.zip)** · [Страница выпуска](https://github.com/dzenlotus/mudra/releases/tag/v0.1.0-preview.20261020)

## Запуск

1. Распакуйте архив.
2. Откройте `Mudra.command`: диалог появится в Терминале.
3. Выберите рабочую папку и настройте свои LLM и embedding API.
4. Напишите задачу в редакторе снизу. **Ctrl+S или F2 отправляет запрос, Enter добавляет строку.** Профиль, знания и разговор сохраняются после закрытия.

Дождитесь открытия редактора перед вставкой первого запроса: в этой preview текст, вставленный вместе с ответами мастеру настройки, может не попасть в чат.

`/help` — команды, `/model` — настроенная модель, `/settings` — настройки, `/status` — диагностика задачи, `/sessions` — сохранённые сессии, `/resume` — явное продолжение, `/new` — новый разговор, `/clear` — очистить экран, `/exit` или `/quit` — выход.

При обновлении распакуйте архив в отдельную папку и запустите новый `Mudra.command`. Сохранённый профиль выберет прежнюю рабочую папку с настройками и знаниями.

## Требования

- Mac с Apple Silicon, macOS 11 или новее.
- Совместимые Chat Completions API с вызовом инструментов и JSON-ответами и embedding API.
- Rust, Python, Node и локальные модели для самого мастера и диалога не нужны.
- Для JavaScript-процедур нужен Node с `process.getBuiltinModule`; проверена версия v24.13.1.

API-ключи задаются через окружение либо macOS Keychain. Ввод ключа в мастере скрыт; ключи не записываются в JSON-настройки. В проверочном SSH-сеансе macOS запретила запись в Keychain (OSStatus -25308); вариант с переменными окружения проверен. `.env` автоматически не загружается.

Архив содержит программу, запуск, инструкцию и контрольные суммы файлов. Рабочие базы, профили и ключи создаются на вашей машине. Рабочая папка не является sandbox: выполняемые процедуры используют права пользователя, а данные могут передаваться выбранным API.

## Что видно при работе

Полноэкранный терминальный интерфейс: прокручиваемая история, отдельный блок действий, текущая фаза, время запроса и доступные счётчики, многострочный редактор снизу. Работают вставка нескольких строк, отмена правки, история запросов с возвратом к черновику и изменение размера окна. Длинные строки в редакторе прокручиваются по горизонтали.

- **Ctrl+S / F2** — отправить весь запрос; также есть кнопка мышью.
- **Enter** — новая строка; Ctrl+Enter отправляет, если терминал отличает его от Enter.
- **↑ / ↓** — история в начале / конце всего текста.
- **PgUp / PgDn** или колесо мыши — прокрутка диалога.
- **Ctrl+D** — показать или скрыть детали; `/status` запрашивает диагностику.
- **Ctrl+Z / Ctrl+Y** — отмена / повтор правки в редакторе.
- **Ctrl+C** — прервать текущий запуск; при ожидании очистить черновик, а при пустом вводе — выйти.

Сообщения Гханты показываются из фактического ответа модели. Запуск действия и его записанный результат выводятся отдельно. Если задача решается готовыми правилами Vajra, отдельного комментария Гханты может не быть. Неизвестный исход прерванного действия обозначается явно.

Для построчного режима запустите `./bin/mudra chat --plain`. При перенаправлении ввода или вывода он выбирается автоматически.

Текущий запрос выполняется в этом окне. Ctrl+C прерывает этот запуск и возвращает ввод; изменения автоматически не откатываются. Сохраняются исходная сессия и сведения о прерванном действии. `/resume` продолжает ту же задачу, а `/clear` очищает только экран. Если в журнале уже есть ожидающее или выполняющееся продолжение этой сессии, параллельный запуск блокируется. Сохранённый статус фоновой записи не подтверждает активность процесса.

Для пояснений не вызывается отдельная модель. В этой версии используются существующие инструменты и знания Ghanta/Vajra; MCP и расширения не добавлены.

## Проверки и статус

На Mac mini прошли сборка, проверка компиляции и 49 существующих проверок CLI. Вручную проверены обычный русский и английский ввод, многострочное редактирование, история с восстановлением черновика, изменение размера окна, диагностика, настройки и выход. В реальном диалоге с `gpt-6.1-sol` (`low`) после уточнения пути выполнено чтение файла: все 186 байт совпали с диском, сохранена одна исходная сессия, учтены оба вызова формализатора. Подробности и границы проверки — в `runtime-receipt.json` выпуска. Корпоративные API подключаются пользователем.

Это preview без Developer ID и нотарификации Apple. Доступ на управляемом Mac может зависеть от политики вашей организации. Общая производственная готовность и задержка с произвольными моделями этими проверками не установлены.

В Assets выпуска доступны архив, `runtime-receipt.json` со сведениями о проверках и `SHA256SUMS`.
