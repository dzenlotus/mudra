# Mudra

Предварительные сборки Mudra — сохраняемого AI harness на основе Ghanta и Vajra.

**[Скачать Mudra для Mac Apple Silicon](https://github.com/dzenlotus/mudra/releases/download/v0.1.0-preview.20261021.1/mudra-macos-arm64-status-preview.zip)** · [Страница выпуска](https://github.com/dzenlotus/mudra/releases/tag/v0.1.0-preview.20261021.1)

## Запуск

1. Распакуйте архив.
2. Откройте `Mudra.command`: диалог появится в Терминале.
3. Выберите рабочую папку и настройте свои LLM и embedding API.
4. Напишите задачу в редакторе снизу. **Ctrl+S или F2 отправляет запрос, Enter добавляет строку.** Профиль, знания и разговор сохраняются после закрытия.

Дождитесь открытия редактора перед вставкой первого запроса: в этой preview текст, вставленный вместе с ответами мастеру настройки, может не попасть в чат.

`/help` — команды, `/model` — настроенная модель, `/settings` — настройки, `/status` — диагностика задачи, `/sessions` — сохранённые сессии, `/resume` — явное продолжение, `/new` — новый разговор, `/clear` — очистить экран, `/exit` или `/quit` — выход.

При обновлении распакуйте архив в отдельную папку и запустите новый `Mudra.command`. Сохранённый профиль выберет прежнюю рабочую папку с настройками и знаниями.

При остановке причина и следующий шаг видны прямо в ответе, а также в начале `/status`. По умолчанию этап выполнения ограничен 16 обращениями к моделям, 96 вызовами инструментов и 64 слоями правил Vajra. Первичный разбор запроса предшествует этому этапу. Общие счётчики сессии сохраняются; граница остановки выводится из записанного события. Для старой записи без причины Mudra явно сообщает, что она неизвестна.

`/resume` выдаёт следующий лимит для той же задачи. Слова «продолжи», «продолжить» и `continue` работают так же для приостановленной задачи. Когда Mudra ждёт уточнения, это остаётся ответом на её вопрос. Три одинаковые ошибки проверки объясняются отдельно: одно продолжение не исправляет ошибочные аргументы. Лимиты настраиваются в `learning.max_model_calls`, `learning.max_tool_calls`, `learning.max_steps` файла `.mudra/config.json`.

## Требования

- Mac с Apple Silicon, macOS 11 или новее.
- Совместимые Chat Completions API с вызовом инструментов и JSON-ответами и embedding API.
- Rust, Python, Node и локальные модели для самого мастера и диалога не нужны.
- Для JavaScript-процедур нужен Node с `process.getBuiltinModule`; проверена версия v24.13.1.

API-ключи задаются через окружение либо macOS Keychain. Ввод ключа в мастере скрыт; ключи не записываются в JSON-настройки. В проверочном SSH-сеансе macOS запретила запись в Keychain (OSStatus -25308); вариант с переменными окружения проверен. `.env` автоматически не загружается.

Архив содержит программу, запуск, инструкцию и контрольные суммы файлов. Рабочие базы, профили и ключи создаются на вашей машине. Рабочая папка не является sandbox: выполняемые процедуры используют права пользователя, а данные могут передаваться выбранным API.

## Что видно при работе

Публичные пояснения Гханты и наблюдавшиеся действия собраны в блок **«Ход работы»**, свёрнутый по умолчанию. Итоговый ответ виден отдельно. **F4 или щелчок по заголовку** раскрывает и сворачивает блок. Старые блоки доступны через прокрутку истории.

Внутри — зарегистрированные вызовы **Vajra: процедура@версия, правило, исход и время вызова**. Показаны записанные внешние исполнения из журнала шага; рекурсивные внутренние вызовы композиции отдельно в этот журнал не записываются. Ошибка, отклонённый кандидат и неизвестный исход обозначаются отдельно. Пояснение модели само по себе не подтверждает результат. Ход работы сохраняется с диалогом и не добавляется к контексту модели.

Справа сверху — **вращаемый 3D-граф пути от входов к цели**. Узлы изображены объёмными шарами с подписями, соединения — сплошными направленными рёбрами. Перспектива, размер и освещение узлов меняются при повороте. Входы выделены бирюзовым, цель — зелёным; параметры, правила, процедуры и контексты различаются по типу и цвету.

**F5 или щелчок по заголовку** разворачивает сам граф на большую область. **F6** переключает его на полный прокручиваемый список узлов и связей и обратно. Редактор запроса остаётся доступен. Длинные названия на сцене сокращаются. Выбор узла показывает его название и тип; полные длинные имена доступны в F6.

Расположение показывает шаги алгоритма. Найденные эмбеддером параметры отмечены **◆**; сохранённые векторы участвуют в пространственной компоновке. Все отображаемые координаты относятся к компоновке графа; score сходства вычисляется в исходном пространстве. Отдельный поток готовит карту без новых вызовов моделей. Узлы без вектора остаются видимы. Неподтверждённые исторические имена и связи явно помечаются.

- **Ctrl+S / F2** — отправить весь запрос; **Enter** — новая строка.
- **F4** или щелчок по заголовку — раскрыть/свернуть «Ход работы».
- **F5** или щелчок по заголовку карты — развернуть 3D-граф / вернуться к диалогу.
- **F6** — полный список узлов и связей / 3D-граф.
- **Alt + стрелки** — вращать карту; **Alt + + / -** или колесо над картой — масштаб.
- **Щелчок по точке** — имя, тип и происхождение координат узла.
- **↑ / ↓** — история запросов в начале / конце всего текста.
- **PgUp / PgDn** — прокрутка диалога; в режиме F6 — списка узлов и связей.
- **Ctrl+D** — детали; `/status` запрашивает диагностику.
- **Ctrl+Z / Ctrl+Y** — отмена / повтор правки в редакторе.
- **Ctrl+C** — прервать текущий запуск; в ожидании очистить черновик, при пустом вводе — выйти.

Карта видна при ширине от 80 столбцов. При меньшей ширине остаётся чат. Редактор сохраняет текст при изменении размеров; длинная строка прокручивается горизонтально.

Текущий запрос выполняется в этом окне. Прерывание сохраняет исходную сессию и неизвестные результаты действий; `/resume` предоставляет явное продолжение. Сохранённая фоновая запись не доказывает активность процесса. Для построчного режима — `./bin/mudra chat --plain`.

## Проверки и статус

Проверено на Mac mini с Apple Silicon:

- Для текущего исправления повторены 49 существующих проверок CLI: все прошли; форматирование и проверка компиляции прошли. Новые продуктовые тесты не добавлялись. Движок, поиск и формат данных не менялись. Свежая проверка сборки и ручные проверки остановки описаны в runtime-receipt.json этого выпуска.

Ниже — результаты проверки 3D-графа из предыдущего выпуска; рендер графа в этом исправлении не менялся:
- Реальные сохранённые задачи показывают 5 узлов/4 связи для чтения файла и 14 узлов/13 связей для трёхшагового расчёта. В F5 виден сам граф, в F6 — все имена и связи. Проверены 80×24, 120×36, 160×50 и список при 80×18.
- Поворот и масштаб изменили 380 ячеек реальной сцены и распределение освещения. Выбор узла, F4/F5/F6, изменение размера окна, черновик и курсор проверены. Исходные сессии и графовые записи не изменены, повторного исполнения задач не было.
- Используются ANSI-256 и собственный тёмный фон графа. Проверены управляющие последовательности и запись терминального буфера, включая светлый профиль; окно Terminal.app отдельно не управлялось и визуально не проверялось.
- Окончательный архив распакован штатной утилитой macOS в путь с пробелами и русскими буквами. Права запуска сохранены; бинарник восстановил сессию и граф без Node в PATH, без вызовов моделей и без нового исполнения процедур.

Один исторический контекст расчёта не имеет подтверждённого имени: он остаётся видимым как `Контекст #186`, с явной отметкой неполных данных. Отображаемые счётчики моделей в сохранённых сессиях относятся к прежним запускам. В этой проверке новых вызовов LLM и эмбеддера не было.

Это preview без Developer ID и нотарификации Apple. Доступ на управляемом Mac может зависеть от политики вашей организации. Общая производственная готовность и задержка с произвольными моделями этими проверками не установлены.

В Assets выпуска доступны архив, `runtime-receipt.json` со сведениями о проверках и `SHA256SUMS`.
